## Decisões e limites desta fase

- `npm run seed --workspace @mente-ativa/api` insere usuários/pacientes de exemplo (com fichas dos nove testes) somente quando ausentes e preserva registros existentes; `POST /api/v1/demo/reset` (admin) apaga dados e restaura as sementes.
- Notas de avaliação não são expostas nos DTOs de fichas.
- As rotas/telas React consomem a API; Playwright cobre login/Home, pacientes, registro manual de ficha, sugestões/rotina, trial e seus credenciais, autorização admin, mobile e tema.
- CORS usa `WEB_ORIGINS`; localmente permite localhost:5173 e 127.0.0.1:5173. Em produção deve-se configurar apenas os domínios da aplicação.
- Smoke test manual validou login e Home seed, e inspeção visual levou ao ajuste dos estilos de links. A comparação visual de todas as telas/estados ainda pode ser aprofundada.
- Hardening da fase 7: Helmet, rate limit em `/auth/*`, CORS allowlist e request logging Pino; integração cobre cabeçalhos Helmet e allow/deny de origem. Configure `JWT_SECRET` forte e `WEB_ORIGINS` no deploy.
- Integração testa com `mongodb-memory-server`; a API normal só começa a escutar após conexão e criação dos índices Mongo. O fallback de JWT é apenas para desenvolvimento; produção deve configurar `JWT_SECRET` forte.
